# Plan — PrimeVue (Aura) layout first

## Goal
Add PrimeVue (Aura) to Vue 3/Inertia/Vite; create layout wrapper (`frontend/src/layout/AppLayout.vue`); keep business logic.

## Assumptions
- Aura Light theme; minimalist (cards, subtle shadows, clean type).
- Start with layout; pages later.

## Step-by-step
1. `frontend/package.json`: add `primevue`, `primeicons`, `@primevue/themes`. `npm install`. Verify `npm ls primevue`.
2. `frontend/src/app.js`: import `PrimeVue`, `Aura`, `primeicons.css`; apply plugin. Verify `npm run build` exit 0.
3. `frontend/src/layout/AppLayout.vue`: new component with `Menubar` / `Card`. Minimalist header + content slot. Ready to wrap pages.
4. Apply to one page (e.g. `frontend/src/pages/Index.vue`): `<AppLayout>`. Verify page renders.

## Tests / validation
- Each step: `npm run build` exit 0.
- No PHP changes; TDD not required for layout.

## Risks
- Bootstrap CSS conflict — resolve by removing Bootstrap import from layout when replaced.
- Version compatibility: PrimeVue 4 + Vue 3.5; pin `primevue@^4`, `@primevue/themes@^4`.


## Confirmed answers
- Theme: Aura
- Scope: layout first, then shop + single product pages
- Minimalist: yes (light, clean cards, subtle shadows)
